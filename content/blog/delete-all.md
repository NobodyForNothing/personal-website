While I was clearing the spam folder in my e-mail client via the clear button, I noticed: I didn't expect the "delete all"-button to delete all e-mails in my spam folder. Rather I expect it to delete all mails the UI currently shows as being in the spam folder. This is an important distinction. If I receive something important miss-flagged as spam, while I'm going through my other, actual, spam, I wouldn't want it get lost. 

This is admittedly quite the edge-case with quite tight timings (at least for me) but I think it is symbolic for what software development is really about: Understanding a problem well enough so that you can define a solution, that matches intuition, rather than doing the verbatim thing you were tasked with.
